## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| Removing ignoreBuildErrors reveals type errors | Run typecheck FIRST before removing flag; fix or suppress |
| ESLint rule re-enabling reveals many errors | Start with warn level; fix incrementally; don't block PR |
| WebCrypto unavailable in test env | jsdom supports crypto.subtle; verify in setup |
| Export-view split breaks imports | Run build after each split step |
| Provider CORS issues in T2 | Test with Ollama (localhost) first; document CORS caveat |
| Tests fail after removing passWithNoTests | Add real tests BEFORE removing the flag |
| Pre-existing CI failures | Check `pnpm run build` first; fix any blockers |
