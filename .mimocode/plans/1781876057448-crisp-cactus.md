## Recommended Track: P0+P1 Items (~50-60h)

This plan scopes the immediate implementation work to the 4 highest-priority areas.

### Wave 1: Security Hardening (Plan 37) — 8-12h

**37.1 — API Key Migration to IndexedDB + Encryption**
- Create `src/lib/key-store.ts` with `IndexedDBKeyStore` class
- Encrypt at rest using Web Crypto (AES-GCM, device-derived key)
- Migrate existing `localStorage` keys on app init
- Remove `VITE_` env var references (ADR 003)
- Files: `src/lib/key-store.ts` (new), `src/lib/llm/config.ts`, `src/lib/security.ts`

**37.2 — SSRF Fix in URL Resolution**
- Validate URL scheme (only `http:`, `https:`) before fetch
- Block `file:`, `data:`, `javascript:`, `ftp:` schemes
- Add to `src/lib/resolver.ts` and `src/lib/search/external-fetch.ts`

**37.3 — Rate Limiter Hardening**
- Move rate limiting logic validation to prevent client bypass
- Add server-side token bucket pattern

**37.4 — Snapshot JSON Validation**
- Add Zod schema validation for snapshot import/load
- Reject malformed JSON with clear error messages
- Files: `src/features/graph/graph-schemas.ts`, `src/features/graph/GraphSnapshotManager.ts`

**37.5 — Browser Migration Fix**
- Fix fallback migration to load all files, not just first
- Files: `src/db/migrate.ts` or migration utility

**37.6 — Silent Catch Logging**
- Audit all `catch {}` blocks, add `logger.error()` with context
- 14 locations to fix across codebase
