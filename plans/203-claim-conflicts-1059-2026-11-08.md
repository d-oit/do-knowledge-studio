# Plan 203 — Claim conflicts/duplicates (#1059)

## Goal

Surface duplicate and possibly contradicting claims without ever auto-modifying
the corpus.

## What changed

- `src/lib/claims/conflicts.ts`: local-first candidate generation (Jaccard over
  `Intl.Segmenter` tokens) + classification (duplicate ≥0.8, contradiction via
  negation / numeric mismatch with ≥0.4 overlap). Contradiction wins over
  near-duplicate. `findClaimConflictsAsync` yields every 200 pairs via
  `queueMicrotask` so typing never blocks.
- `src/lib/claims/conflict-dismissals.ts`: dismissed `idA|idB` keys in the
  localStorage metadata envelope, Zod-validated, survive reload/sync.
- `src/lib/claims/conflicts.fixtures.ts` + tests: 4/4 recall on labeled
  duplicates/contradictions, 0 false positives on unrelated fixtures.
- `src/components/studio/views/claim-conflicts-panel.tsx`: lists pairs with
  both statements, confidence, entity names, suggestion disclaimer; merge
  (keeps A, deletes B), mark superseded (disputed), dismiss. All route through
  `pushHistory` (undoable).
- `src/lib/i18n/messages/conflicts.ts`: translatable strings.
