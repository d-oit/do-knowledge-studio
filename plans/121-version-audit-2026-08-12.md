# Plan 121 — Version Consistency Audit (2026-08-12)

Date: 2026-08-12
Status: COMPLETE

## Purpose

Validate that `VERSION` (single source of truth, now `0.1.2`) is used
correctly across the complete application: UI output, docs (.md), and
functional code.

## Audit Findings

### Fixed — UI version badge was hardcoded and stale

| File | Before | After |
|------|--------|-------|
| `src/components/studio/sidebar.tsx` | `Local-first · v0.2` (hardcoded) | `Local-first · v{packageJson.version}` (dynamic) |
| `src/components/studio/mobile-drawer.tsx` | `Local-first · v0.2` (hardcoded) | `Local-first · v{packageJson.version}` (dynamic) |

The badge displayed `v0.2` while `VERSION` was `0.1.1`. Both components now
import `package.json` (matching the existing convention in
`use-export-handlers.ts`) so the badge can never drift from the release
version again.

### Fixed — stale docs references

| `agents-docs/VERSION.md` | 28 | `\| VERSION \| 0.1.0 \|` | `0.1.2` |
