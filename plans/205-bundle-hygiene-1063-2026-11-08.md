# Plan 205 — Bundle hygiene (#1063)

## Findings

- `sharp`: direct dependency removed; kept in devDependencies for the
  `impeccable` OG-image skill script. Production still resolves `sharp`
  transitively via `next` (image optimization) and `@huggingface/transformers`
  — `pnpm why sharp` confirms. No `src/`, `scripts/` (app) or config imports
  `sharp` directly.
- Heavy export libs: `use-export-handlers.ts` already dynamic-imports
  `./export-documents` (jspdf + docx) on first PDF/DOCX click; OKF/encrypted
  paths dynamic-import `fflate` / `encrypt`. Fixed the gap:
  `mindmap-export.ts` statically imported `html2canvas` via `mindmap-view`;
  now `await import('html2canvas')` inside `exportElementAsPng`, so opening the
  mind map no longer downloads the rasterizer.
- Unused shadcn/Radix: `src/components/ui/*` (~40 files) has almost no imports
  from `src/` — the app uses `src/components/studio/ui/shared-primitives`.
  Decision: explicitly kept (shadcn vendor scaffolding, AGENTS.md 500-LOC
  exception); removal would churn vendor code for no first-load win since they
  are not bundled unless imported. `scripts/check-unused-ui.mjs` runs as an
  advisory CI log.
- `dev` pipe to `dev.log` via `tee`: verified `dev.log` is gitignored (check
  `.gitignore`).
