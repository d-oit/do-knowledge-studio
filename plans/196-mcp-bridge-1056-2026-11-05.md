# Plan 196 — MCP Bridge (#1056): Offline Bundle Server

ADR 050 accepts option A. This plan tracks the build.

## Scope

- `pnpm-workspace.yaml` (`packages/*`); `packages/dks-mcp` package.
- Reader: zip (strip `okf-bundle/` prefix) or directory → concepts.
  Guards: entry-count cap, per-file cap, total-decompression cap, path
  sanitize. Reserved `index.md` (requires `okf_version 0.2.x`) and `log.md`.
- Parse per concept: frontmatter (title/type/description/tags/sources/
  verified/status), `# Claims` list with `[^id]` footnote join (mirror
  `parseClaims`), `# Related` markdown links for adjacency.
- Index: entity by id + case-insensitive name, claims by entity, adjacency,
  tag census, BM25-lite search over name + description + content + claims.
- Tools (Zod-validated): `search {query, limit}`, `get_entity {id|name}`,
  `get_claims {entityId|entityName, verifiedOnly?}`, `neighborhood {id|name}`,
  `list_tags {}`. Results carry `verification`, `sources`, concept
  `trustTier`, and a prompt-injection note is documented in the README.
- Server wiring (`Server` + `StdioServerTransport`), CLI
  (`dks-mcp serve <path>`, exit non-zero on unreadable bundle).
- Tests (package vitest): reader fixtures (zip + dir, hostile paths,
  oversize, bad version), index/search behavior, trust derivation parity,
  InMemoryTransport contract test (list + call every tool, error shapes).
- README: Claude Code / Claude Desktop config snippets, capability notes.
- Root wiring: `test` and `typecheck` chain the package scripts.
- Gates: package `vitest`, `tsc`, root `lint`/`typecheck`/`test`/`build`,
  then code-review-assistant, PR, merge when all CI green.

## Non-goals

- `find_path` (waits for #1058), write tools, WebSocket bridge, WebMCP,
  publishing to npm.
