# Typography Reference

## Font Stack

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, sans-serif;
```

## Scale

| Element | Size | Weight | Line Height |
|---------|------|--------|-------------|
| H1 | 24px | 700 | 1.2 |
| H2 | 20px | 600 | 1.3 |
| H3 | 16px | 600 | 1.4 |
| Body | 14px | 400 | 1.5 |
| Small | 12px | 400 | 1.4 |
| Caption | 11px | 400 | 1.3 |

## Rules

- Never use `font-weight: 300` below 16px
- Minimum 12px for any visible text
- Code: use `monospace` only for actual code
- Truncate with ellipsis: `text-overflow: ellipsis; white-space: nowrap; overflow: hidden`
